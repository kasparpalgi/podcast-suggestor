# Podcast suggestor

Enter website or LinkedIn and email address and the system emails a list of about 10 relevant podcasts. It can resend a fresh list on a weekly schedule. 

## Developing

Install with `pnpm install`, rename `.env.example` to `.env` and fill the values and start a development server:

```sh
pnpm run dev

## Building

To create a production version of your app:

```sh
pnpm run build
```

You can preview the production build with `pnpm run preview`.
